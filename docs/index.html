§04 · Papers and Case Studies

Papers and Case Studies

  • Architecture meta-model for MagicGrid (2024) - INCOSE 2024 paper proposing a systems architecture meta-model for the MagicGrid framework by No Magic methodology staff (Aleksandraviciene, Strolia, Morkevicius).
  • Extending MagicGrid for virtual prototyping (2024) - ACM 2024 paper on extending MagicGrid to support virtual prototyping for early system performance V&V.
  • Flight-control requirements case study (2024) - Springer 2024 case study on a MagicGrid-based requirements development process for a flight control system.
  • Mainstream MBSE methodologies survey (2022) - Survey from 2022 comparing mainstream MBSE methodologies from a modeling-practice view, including MagicGrid.
  • MBSE Grid hydroelectric health-monitoring case (2022) - Springer 2022 case applying MBSE Grid operational analysis to a hydroelectric group health monitoring unit.
  • MBSE Grid origin paper (2017) - INCOSE 2017 paper introducing MBSE Grid, the precursor to MagicGrid, by No Magic methodology staff.
  • Space remote-sensing case study (2020) - Springer 2020 case study applying MagicGrid methodology to a space-borne remote sensing imaging system.
  • SysML v1 vs v2 in MagicGrid scope (2024) - INCOSE 2024 paper comparing SysML v1 and SysML v2 application within the MagicGrid framework by No Magic methodology staff.
  • SysML v2 solution architecture with MagicGrid (2025) - INCOSE 2025 paper exploring SysML v2 for solution architecture development with the MagicGrid framework.
  • System V&V using MagicGrid (INSIGHT 2023) - INSIGHT 2023 article on a system verification and validation approach using the MagicGrid framework by No Magic methodology staff (Morkevicius et al.).
  • System V&V using MagicGrid (IS 2022) - INCOSE IS 2022 paper on a system verification and validation approach using the MagicGrid framework by No Magic methodology staff (Morkevicius et al.).
  • Towards a Common SE Methodology (2020) - INCOSE 2020 paper toward a common systems engineering methodology covering a complete development process grounded in MBSE Grid.

§11 · Install and usage

Install and usage

Nothing to install. This list is a curated index: browse it here on GitHub, or clone the repository.

Use the section links in the navigation at the top of the page to jump to a section, or search the page with your browser's find function. Open any entry's link to reach the upstream resource; the list never re-hosts content. To suggest a resource or report a defect, open an issue, or open a pull request that follows contributing.md. Security issues go through a private security advisory (see SECURITY.md).
